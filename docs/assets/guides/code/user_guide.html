The ShapeX workflow

From image annotations to a practical spatial sampling plan

ShapeX is a QuPath extension for connecting regions identified in a digital image with the physical samples collected from them. It brings annotation selection, spatial subdivision, plate assignment, and output generation into one coordinated workflow, so the path from image to well remains clear and reviewable.

What ShapeX is for

Keep spatial decisions connected from the image to the laboratory

Spatial experiments often begin with a visual decision: a researcher identifies tissue, structures, phenotypes, or other regions of interest in an image. The next steps are physical. Those regions must become samples, the samples must be assigned to collection positions, and the resulting plan must be communicated to laboratory instruments and downstream analysis tools. ShapeX is designed to make that transition explicit rather than leaving it spread across screenshots, handwritten notes, and separate spreadsheets.

The workflow starts with area annotations in a QuPath project. An annotation can be used directly as one sample, grouped with related annotations, or divided into smaller, regularly arranged regions. ShapeX then maps the selected samples to wells and provides a visual plate preview before any files are generated. This makes it possible to inspect how image-derived material will be organized while the spatial origin of every sample is still available.

How to use this guide

Follow the workflow, then explore ShapeX

This section guides you through a typical ShapeX workflow, from annotating regions in QuPath to reviewing the generated outputs. The other tabs contain interactive previews of the ShapeX interface. Explore their controls to familiarize yourself with the extension.

A typical journey

  1. Annotating

    Using QuPath’s built-in annotation tools, mark your regions of interest, whether they are cells or other structures. ShapeX accepts all closed shapes. These are shapes the laser-microdissection system can follow in a single continuous track without stopping or moving to a new position. Shapes that are not closed are marked in QuPath as “Geometry” under the “ROI” key. During annotation processing, ShapeX will attempt to handle geometries but will request manual review when the result is ambiguous.

    For larger regions, ShapeX includes the Shape Tessellator. This tool divides large annotations into smaller, regularly arranged regions, allowing you to control the size and number of samples generated from a single annotation. The resulting layout also supports spatial reconstruction of the original annotation after downstream analysis. In a laser-microdissection workflow, each tessellated region can be collected in its own well while retaining its link to its original spatial position. Molecular signatures can then be compared across the tessellated regions to identify spatial heterogeneity within the original annotation.

  2. Adding calibration points

    The microscope needs three calibration points to align its internal coordinate system with the coordinate system used by QuPath. These points allow the microscope to determine how the imported annotations must be rotated, translated, and scaled to match its internal coordinates. QuPath provides two ways to create point annotations: single points and multipoints. To create them, select the tool represented by three circles arranged in a triangle to open the Points menu. ShapeX accepts either one multipoint annotation containing exactly three points or exactly three single-point annotations. If more than three single-point annotations are available, ShapeX asks you to select exactly three during export. The points do not need specific names. ShapeX marks images that are missing the required calibration points so that they can be identified and corrected before export.

    When , consider their distribution and how easy they will be to locate on the microscope. Keep the points well separated and avoid arranging them in a straight line. When the points are close together, even small placement errors can reduce alignment accuracy. Spreading the points farther apart makes the alignment more reliable. Place the points so that they form a large triangle spanning the relevant tissue area. Choose distinctive landmarks that are easy to find on the microscope. Tissue crevices and corners often work well because they help you position the corresponding microscope points more precisely.

  3. Designing your plates

    The Plate Designer is the heart of ShapeX. It lets you create a plate layout tailored to your workflow and preview how samples will be assigned before exporting any files. You can choose a standard 96-, 384-, or 1536-well format, or define a custom plate by setting its number of rows and columns.

    After selecting the slides and annotations to include, you can pool samples by class, create separate plates for individual images, randomize assignments, reserve negative-control wells, mark wells as unavailable, or edit the layout manually. ShapeX distributes samples across additional plates when needed and lets you review each plate before export.

  4. Choosing outputs

    Once your plate design is ready, Outputs lets you choose what ShapeX should generate. Available outputs include laser-microdissection annotation files, plate overviews, liquid dispensing instructions, and AnnData files for downstream spatial analysis. Each output can be enabled independently, so you only generate the files needed for your workflow.

    Check your output settings, choose where the files should be saved, and run the export. Before writing any files, ShapeX checks the selected slides, plate assignments, required calibration points, and geometries that may need manual review. Always review the generated files before using them with laboratory equipment or downstream software.

  5. Reviewing and using your outputs

    Geometry handling. Before generating any outputs, ShapeX checks the exported annotations for geometries that may need attention. It automatically handles small issues, but if an annotation still contains disconnected components, ShapeX asks whether to merge the components, keep them, skip the affected annotation, or review it manually. Choosing manual review pauses the export so that you can inspect the affected annotations before running it again.

    After a successful run, ShapeX creates an output folder in the selected location. By default, this is the QuPath project folder. The first export in that location is saved in a folder named ShapeX. If that folder already exists, later exports use the date and time followed by _ShapeX, for example 20260723_151759_ShapeX, to prevent previous exports from being overwritten.

    Depending on what you select, ShapeX can create four types of output: laser-microdissection files for supported cutting systems, liquid-dispensing files, a plate overview that records the plate and well assignments, and an AnnData file containing annotation data for downstream analysis. ShapeX only creates the output types selected for the run. Instructions for using the instrument-specific files are available in the cards below.

Limitations

Current instrument support

ShapeX currently supports only laser-microdissection output for Leica LMD systems and liquid-dispensing output for Dispendix i.DOT systems, but we would love to add support for more systems. Each integration requires reliable information about the system’s file formats and workflow. If there is an instrument, data structure, or anything else you would like ShapeX to support, please reach out to us on GitHub.

Community contributions are therefore highly appreciated. If you can share file-format specifications, example files, or workflow documentation for another system, please open a GitHub issue and tell us what you would like ShapeX to support.
